# Dragnet

A keyword-driven internship posting monitor. Sweeps free aggregator APIs, normalizes results, scores and dedupes them, and emits a daily markdown brief plus a Gmail digest.

## Quick start

See `docs/SETUP.md` for installation, API key registration, and the first-run smoke test. See `docs/LAYER1_NATIVE_ALERTS.md` for the companion native-alert setup on platforms Dragnet doesn't cover directly.
